# AI agent 收件箱

最近看到一个叫 Pizza Bot 的开源项目，它把后台运行的 AI agent 任务映射到一个类似电子邮件的收件箱界面。完成的工作进入 Unread，等待审批的操作进入 Action。这个设计解决了一个关键问题：当 AI agent 从同步对话转向异步执行时，用户如何管理多个并发任务而不被实时打断。

传统聊天界面要求用户保持会话活跃，而长时间任务会占用注意力并造成上下文断裂。Pizza Bot 用收件箱隐喻重新组织工作状态：Unread 和 Action 队列提供了清晰的优先级和决策点，降低了管理多个并发 agent 任务的认知负担。

人工审批机制将高风险操作的控制权保留给用户，同时允许低风险任务自动完成，平衡了效率与安全。支持多种模型提供商和本地模型降低了使用门槛，而显式的文件访问授权增强了信任。

但桌面应用的形态限制了真正的异步性：计算机关闭时任务无法运行，除非部署独立后端。与现有工单系统（如 Linear）或简单文件监控方案相比，Pizza Bot 的差异化价值尚不明确。
