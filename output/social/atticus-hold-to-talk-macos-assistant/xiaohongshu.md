# AI助手越用越快？

最近看到一个叫 Atticus 的 macOS 语音助手，作者是个九年级学生。它最吸引我的不是能调用 Claude，而是它把 AI 从每次交互的必经环节变成了学习器和兜底者。

按住快捷键说话，简单任务像打开应用、移动窗口，本地规则直接处理，0.08 秒就能完成。复杂任务才交给 Claude，而且不需要自己的 API key，直接用已有的 Claude Pro 或 Max 计划。

最妙的是它的快捷方式学习机制。第一次成功完成任务后，它会记录步骤，下次直接重放。比如“打开计算器和国际象棋”，首次要 5.5 秒，之后只要 0.4 秒。用得越多，高频操作就越快越便宜。

但我也担心一个问题：如果应用更新导致界面变化，已保存的快捷方式失效了怎么办？证据里没有说明检测和更新机制。如果积累了大量快捷方式却无法自动更新，那“越用越快”可能会变成“越用越容易出错”。

这种“记录一次、重放多次”的思路，对 AI 产品经理很有启发：不要把所有任务都交给大模型，而是识别哪些可以本地化、规则化，并让 AI 的学习成果沉淀为可复用的资产。

你觉得快捷方式库的自动更新机制，是这类产品成功的关键吗？
