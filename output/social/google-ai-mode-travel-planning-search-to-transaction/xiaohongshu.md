# Google把旅行预订塞进AI Mode

最近 Google 在 Search 的 AI Mode 里加入了航班价格追踪、积分兑换查询和酒店预订。我试了一下，确实方便：不用在 Google Flights、航空公司和酒店官网之间来回跳，一个对话就能搞定。

但用着用着，我发现一个关键问题：推荐排序不透明。比如搜酒店，AI Mode 会列出合作方，但我不知道排在前面的酒店是因为价格最优、评分最高，还是因为它是合作方。如果我不能验证排序依据，我可能会回到 Kayak 或直接去航空公司官网做最终决定。

积分兑换功能初始合作伙伴有限，酒店预订也仅在美国英语环境推出。对话式界面适合简单行程，复杂多城市行程还是得靠传统工具。

AI Mode 的旅行功能更像一个试点，解决了简单场景的效率问题，但商业信任还没建立。Google 需要在产品里明确标注商业关系，提供可验证的排序依据。

你会因为方便而在 AI Mode 里直接预订酒店，还是坚持去比价网站确认后再下单？
